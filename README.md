# 跨境选品工具链（采集 → 清洗 → 成本核算 → 评分）

> 把「这个品能不能做」「这批货赚不赚钱」从拍脑袋变成算数字。
> 作者：夏才艺（工业互联网应用专业在读）｜数据与代码均为真实产出，可复现。

## 解决什么问题

外贸业务员选品 / 报价时最容易犯两类错：

1. **行情靠印象**——不知道目标品类的真实价格区间和竞争密度，就敢报 FOB。
2. **成本算重复**——把 EXW / FOB / CIF 当成并列项去相减，同一笔钱扣三遍；而占采购价 13% 的**出口退税**经常整个被漏掉。

本工具链把这两个判断做成可复现的计算：**FOB 净利 = FOB 收入 + 出口退税 − 采购含税价 − 国内杂费**，退税按 `采购含税价 ÷ (1 + 进项税率) × 退税率` 计回。

## 流水线

```
spider.py  采集  阿里国际站真实商品页（DrissionPage 真实浏览器驱动）
    ↓
阿里原始.csv（137 条）
    ↓
clean.py   清洗  区间报价解析 / 千分位金额 / 起订量单位换算 / 去重
    ↓
阿里清洗.csv（121 条）
    ↓
cost.py    成本  出口退税 rebate() + FOB 净利 fob_profit()
    ↓
score.py   评分  利润 45 / 需求 30 / 竞争 25（反向），A/B/C 分级，导出 CSV
    ↓
选品评分.csv
```

## 各模块说明

| 模块 | 做什么 | 关键实现 |
|---|---|---|
| `spider.py` | 采集阿里国际站搜索结果页 | 真实浏览器驱动攻克动态渲染；读取卡片属性**剔除广告位**；随机延时防反爬；自动翻页 |
| `clean.py` | 把商品页文本变成可计算的数字 | 解析区间报价（`¥19.03-32.38`）、千分位（`1,000`）、计价单位换算（kilogram→单件按重量折算） |
| `cost.py` | 出口成本核算 | `rebate()` 退税收入（`round()` 处理浮点误差）；`fob_profit()` 单件净利 + 利润率；本地真实物流参数（济宁→青岛拖车 / 报关 / 港杂 / 电汇） |
| `score.py` | 选品评分与报表 | 三维度加权打分，竞争为反向指标；`score_one()` 单品全链路计算；`export_csv()` 导出报表 |

## 实测结果

- 采集：**原始 137 条 → 去重后 131 条 → 清洗后有效 121 条**（品类：挖掘机斗齿 1U3352，工程机械易损件）
- 单位分布：piece/pieces 102 · kilogram(s) 25 · box 3 · pack 2 · 其他 8
- 评分示例：斗齿 500 件 **74.8 分（A 级）**；滤芯 300 件 **45.2 分（C 级）**——识别出「滤芯利润率 19.4% 并不差，但需求低 + 竞争大导致总分掉档」，单看利润率会误判
- 成本模型通过异值测试：100 件利润率 4.9% / 500 件 24.6%，验证规模对净利的杠杆效应

## 怎么运行

```bash
# 环境要求：Python 3.11+，爬虫需要 Chrome 浏览器
pip install DrissionPage

# 1. 采集（需可访问阿里国际站）
python spider.py

# 2. 清洗
python clean.py

# 3. 成本核算 + 评分导出
python score.py
```

## 已知局限（诚实版）

- `clean.py` 的汇率常量（6.68）与 `cost.py`（7.10）尚未统一，串联使用前需对齐
- `kilograms→单件` 的折算重量目前硬编码为斗齿规格（6.0 kg），换品类需改参数
- 爬虫暂未采集「90 天成交数」与「供应商数量」字段，评分中的需求分 / 竞争分目前以手工估值为输入
- 退税率 13% 待按 HS 编码（8431 项下）核实当期退税率文库

## 数据来源说明

CSV 数据来自阿里国际站公开搜索结果页（2026-10 采集），仅含公开商品标题、价格区间与起订量，不含任何个人数据。
